DocuFire on Any Computer

On a Mac, DocuFire is a native app from the App Store, the same one as the iPad. On a Windows PC or any other computer, use the DocuFire web portal: the same cases, in any browser, signed in with the same Apple ID your iPad uses. Type up witness statements, fill in sections, draft the Scene Summary, mark sections complete — everything syncs both ways. It comes with DocuFire, nothing extra to buy.

What the portal is and isn't

The portal is a web app built for finishing reports at a desk. Scene documentation — photos, scene diagrams, LiDAR scans, signatures — still happens on the iPad, and the final PDF and Word export happens in the app (iPad or Mac). If you need something the portal doesn't do yet, email and tell me.

Open portal.docufire.app
Sign in with the same Apple ID as your iPad. If you're not a DocuFire user yet, start with the iPad app.

The Honest Version

DocuFire is built natively on Apple's tools — SwiftUI and iCloud — which is why it works the way it does on iPad and Mac. Rather than rebuild all of that for every other kind of computer, I built the part investigators actually asked for away from the iPad: the desk work. The portal reads and writes the same iCloud data the iPad does, so there's no import, no export, no second copy of anything.

If the portal turns out not to cover what you need at the desk, email me with what's missing — that's what decides what gets built next.

Roger reads and answers every message himself.
